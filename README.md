# Zyllo Tech website

Vite + React + react-router + Tailwind v4 + Supabase. Hosted on Lovable.

- `npm install && npm run dev` (http://localhost:3000), `npm run build`
- Copy `.env.example` to `.env.local` and set the `VITE_*` values.
- Backend: `supabase/policies/*.sql` (RLS) and `supabase/functions/*` (Edge Functions). See `supabase/DEPLOY.md`.

See **SETUP.md** for the complete setup (packages, environment, database, Edge Functions, dashboard settings).
